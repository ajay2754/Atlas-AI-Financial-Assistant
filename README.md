💰 Atlas AI Financial Assistant

Atlas AI Financial Assistant is an AI-powered financial web application designed to provide an intelligent and user-friendly experience for understanding and managing financial information.

The application combines a modern React + TypeScript frontend, an Express/Node.js backend, and Google Gemini AI capabilities.

✨ Features

- 🤖 AI-powered financial assistant
- 💬 Interactive financial conversations
- 📊 Financial data visualization
- 📈 Charts and analytical insights
- ⚡ Fast and responsive user interface
- 🎨 Modern UI/UX
- 📱 Responsive web design
- 🔐 Environment-based API configuration
- 🧠 Google Gemini AI integration

🚀 Running the Project Locally

1. Clone the repository

git clone https://github.com/ajay2754/Atlas-AI-Financial-Assistant.git

2. Install dependencies

npm install

3. Configure environment variables

Create a ".env" file and configure the required environment variables.

«Never commit private API keys or secrets to GitHub.»

4. Start the application

npm run dev

5. Build for production

npm run build

The purpose of Atlas AI Financial Assistant is to explore how Generative AI and modern web technologies can be combined to create intelligent financial applications with conversational AI, analytics, and an easy-to-use interface.
